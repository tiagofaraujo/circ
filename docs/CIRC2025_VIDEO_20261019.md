# CIRC 2025 — homepage film feature

## Placement and scope
- The organiser supplied https://youtu.be/bvVn2Bl3BRw as the previous-edition video.
- The homepage archive teaser is replaced with an editorial film section immediately after the programme/attendance/partnership cards and before SocialConnect.
- Stable anchor: `/#circ2025-video`. Archive link `/2025` is preserved; the archive itself, hero, programme and personal area are unchanged.
- The thumbnail is the existing local `/circ2025/hero-auditorium.webp` photograph. It is an editorial cover, not claimed to be a frame of the video.

## Presentation and behaviour
- PT: “CIRC 2025, em filme.” EN: “CIRC 2025, on film.” Uses the existing CIRC colours, typography and language context.
- Responsive video frame, minimum 200 px height, keyboard play, labelled iframe, fullscreen and close/unload control with focus restoration.
- No YouTube iframe, image, script or preconnect before the visitor activates the clearly labelled play button; provider notice is visible before activation.
- Uses the official `youtube-nocookie.com` embed. Autoplay is requested only after the visitor clicks; browser restrictions can still require the native player play control.
- The direct YouTube link remains available for embedding restrictions or network failures. No claim is made about video duration, upload date, captions or production credit.
- No new application dependency, analytics, stored consent preference or payment/fiscal operation.

## Validation
- React tests cover PT/EN, the exact supplied video, first-party lazy cover, click-to-load, referrer policy, fullscreen, close/focus and fallback link.
- Isolated GitHub Actions runs full frontend regression tests, the production build and Chromium screenshots at 1440, 1280, 390 and 320 px.
- Browser checks use mocked external requests, not live YouTube playback. A successful bundle/CI is not, by itself, proof of production deployment or of YouTube embedding availability.
