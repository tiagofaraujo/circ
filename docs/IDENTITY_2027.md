# CIRC 2027 visual identity

Implemented from organisation-supplied `Cores(2).pdf` and `CIRC27_PROPA1(2).pdf` (25 September 2026).

- Primary blue: #232EB7 (retained).
- Dark blue: #20167F.
- Accent red: #F7301D.
- Paper: #F2F1F0.
- Lilac: #CBC3E2; peach: #FBA299.
- Main typeface: Inter, locally served variable WOFF2, Latin and Latin Extended. Font licence in public/fonts/Inter-LICENSE.txt.
- Alike Angular remains available for selected existing display elements.

The bell image is a direct PDF rendering of the right-hand artwork on page 4 (1-indexed), excluding the presentation text. The surrounding #2E3190 background matches the supplied artwork. The slogan is live HTML for accessibility and responsive layout. Light peach is used for the hero slogan to maintain legibility against the blue.

The presentation poster shows 4–5 April 2027, which conflicts with the approved website programme (courses 8 April; congress 9–10 April). The existing programme dates are retained pending clarification; the poster itself is not published with conflicting dates.

Visual verification: main public pages at 1440px, 390px and 320px; Inter loading; mobile navigation and language switching; no page errors or broken images. No payment or registration logic changed.
